**Kurz-Anleitung für die Steam Machine:**
1. Oben auf den Download-Link klicken (die Datei landet im Ordner `Downloads`).
2. Im Dateimanager Rechtsklick auf `Trafik-Dorf-x86_64.AppImage` → **Eigenschaften** → **Berechtigungen** → Haken bei **Ausführbar** setzen.
3. In Steam unten links auf **Spiel hinzufügen** → **Ein Nicht-Steam-Spiel hinzufügen …** → über **Durchsuchen** die Datei aus `Downloads` wählen.
4. Im Spiel unter **Esc → Menü & Hilfe → „Nach Update suchen“** holst du dir jederzeit die neueste Version. Dein Spielstand bleibt dabei erhalten.
